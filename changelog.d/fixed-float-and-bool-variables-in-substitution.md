- Float and bool variables now substitute into `{VAR}` tokens and appear in the variable picker.
  Before, a `{VAR}` token for one of these stayed in the text as typed. A float renders as `1.5`
  and a bool as `true` or `false`.
  [#5839](https://github.com/griptape-ai/griptape-nodes-engine/issues/5839)
